🛒 Order List Manager

A simple web app to manage your shop orders on the spot. Add products, manage your order list, and send orders via WhatsApp. Everything is stored locally in your browser using Local Storage — no backend needed!

⚡ Features

Add products with name and quantity on the spot

View, edit, delete, and mark products as completed

Select products and send order directly via WhatsApp

Products are saved in Local Storage — persist after refreshing

Clear all products easily when done

📌 How to Use

Open index.html in your browser (mobile or desktop).

Add a Product Name and Quantity, then click Add.

Use the checkbox to select products to send.

Enter the WhatsApp number and click Send Selected to WhatsApp.

Use ✅ to mark products completed and 🗑 to delete.

🖥️ Technologies Used

HTML5

Bootstrap & CSS (for styling)

JavaScript (for logic & Local Storage)


📂 Project Structure
